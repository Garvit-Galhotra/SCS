# Starting of Backend

# what are packages?

- some kind of code which we have not written but someone else has written it and it is publically available so that developer like us can use them

# How to use and install those packages

1. Using cat-me backend as an example now
   - how to download
   1. in the terminal use this command -> npm i cat-me
   - how to use
   1. need to use the require("name of the package")

2. what is the use of the package.json
   - just to write what we have used in the project like the different packages we have used in the same project with their version

3. what is the use of the node_modules
   - code from the package which is online will come to this folder
   - the main code for that particular package from the webstie like npm.js website

4. what is the use of the package-lock.json
   - maintains the packages which is inside the node-modules folder
