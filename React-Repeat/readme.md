# Why we need Reactjs

    - brings us the concept of virtual dom
    - only component will refresh not the full website

# what is virtual dom and real dom

    - real dom -> actual dom
    - vitual dom -> copy of real dom

# Reconcilation

    - it is a process where virtual dom compares/diffing to real dom and whatever changes occur it will render that part
